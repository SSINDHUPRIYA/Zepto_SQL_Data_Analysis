🛒 Zepto Product Data Analysis — SQL Project

📌 About the Project

This is my first SQL project where I analyzed a real-world e-commerce inventory dataset from **Zepto** — one of India's 
fastest-growing quick-commerce startups. The dataset was sourced from Kaggle and contains product-level data including 
pricing, discounts, stock availability, and weight details.
In this project I performed data exploration, data cleaning and wrote business-driven SQL queries to extract useful 
insights from the data.

🛠️ SQL Concepts I Learned

- ALTER TABLE
- Data Exploration (COUNT, LIMIT, NULL checks)
- Data Cleaning (DELETE, UPDATE, price conversion)
- DISTINCT, ORDER BY, GROUP BY, HAVING
- Aggregate Functions (SUM, AVG, ROUND)
- CASE WHEN (conditional categorization)
- Subqueries & Filtering (WHERE with multiple conditions)

💡 Business Insights Extracted
- Top 10 best value products by discounted price
- High MRP products that are out of stock
- Estimated revenue per category
- Products with MRP > ₹500 but discount < 10%
- Top 5 categories with highest average discount
- Price per gram for products above 100g
- Products grouped into Low / Medium / Bulk by weight
- Total inventory weight per category
